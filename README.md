# Тренажёр НББС

Интерактивный тренажёр памяти по предметам НББС.

## Структура

- `js/data/` — данные (вопросы, книги, режимы). Меняются здесь.
- `js/state.js` — состояние (текущий предмет, выбранные книги).
- `js/progress.js` — сохранение прогресса в localStorage.
- `js/ui.js` — отрисовка DOM, навигация.
- `js/game.js` — игровой цикл.
- `js/app.js` — обработчики событий.

## Как добавить вопрос

1. Откройте `js/data/ot-questions.js` (или `bs-questions.js`)
2. Добавьте объект в массив:
```js
{
  book: "Бытие",
  category: "Цель",
  q: "Текст вопроса?",
  a: ["Правильный", "Неверный 1", "Неверный 2", "Неверный 3"],
  correct: 0,   // индекс правильного в массиве a
  why: "Пояснение к ответу."
}
